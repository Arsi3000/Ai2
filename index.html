1 · Вход
Без галочки живёт до закрытия вкладки. На чужом телефоне не ставьте.
2 · Модель
Локально на телефоне — без интернета
Считается на GPU телефона: ни сети, ни ключей, ни отправки данных. Скачивается один раз и остаётся в памяти устройства; при следующих запусках плашка показывает «⚡ из памяти» — это чтение с телефона, а не загрузка из сети (занимает 20–60 секунд). Работает только на https: при открытии из «Файлов» кэша нет и модель качается заново.
3 · Очередь ключей
Сначала самые быстрые и бесплатные. Ключ с ответом «лимит» отдыхает и пропускается.
4 · Ключи из GitHub
На GitHub откройте файл → «Raw» → скопируйте адрес. Репозиторий должен быть публичным.
Файл в репозитории зашифрован AES-GCM. Пин из 4–6 цифр подбирается за секунды — лучше 12+ знаков.
